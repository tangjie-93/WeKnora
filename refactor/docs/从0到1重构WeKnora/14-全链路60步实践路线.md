# 从一份文档到整个项目：全链路 `60` 步实践路线

[目录](./00-目录.md) · [总路线](./01-总路线与学习方法.md) · [进度记录](./13-进度与验收记录.md)

本路线将“文档上传到用户问答”的原理直接编入实施顺序：先认识系统，再让资料进入系统、让问题找到证据、让答案可靠保存，最后沿这些能力扩展到完整产品。重点是中间的 `33` 步主链路实验，而不是只在最后得到一个能回答的页面。

## 1. 怎样使用这些步骤

本文件用于选择当前要推进的工作；具体实现细节直接写在 `02–12` 对应阶段章节的原任务下面。遇到“保存”“校验”“生成”等动作，沿同章新增拆解确定修改文件、传入数据、调用顺序和检查结果，不切换到另一套入门课程。

项目阶段仍是 `S0–S10`。下表的步骤号只表示学习顺序；“对应任务”指向既有实施章的任务，不增加另一套完成率。一个原任务可以拆成几次实验；一个功能组也可能需要多天完成，`60` 步不表示 `60` 天或全部功能只有 `60` 项。

每一步按“读原理 → 找原版调用入口 → 确认输入输出和数据归属 → 实现 → 故意失败 → 解释结果”推进。目标代码仍在 `python/backend/` 和 `python/frontend/`，服务层编排业务、仓储层保存数据，保留原数据库和 `/api/v1` 契约。

只读懂原理记为“已阅读”；动手但未验证记为“实现中”；成功与失败证据齐全才能标记“已验收”。下面所有步骤均为待执行计划。旧分析基线是 `5e65ef7`，原总路线记录的是 `930cc8c`；实际行为统一以你在 `S0` 冻结的版本和运行模式为准。

### 1.2 一套材料贯穿全程

在独立测试环境准备自制的 `采购规则.md`：包含“超过十万元由财务负责人复核”“设备申领由部门主管确认”，再加入一条明确的例外条件，检验裁剪是否丢失条件。以后按需增加带页码的文本型 `PDF`、扫描件、表格和图片，不从第一步就处理所有格式。

准备两个无共享权限的测试租户，再在共享模块增加显式授权。每次记录文档、块、会话与助手消息标识，但不在公开日志放正文和凭据。假模型用于时序与契约，真实模型用于语义与质量，两类证据分开。

| `05 / S3` 身份与租户 | 实现登录、刷新、退出和资源授权，准备两个租户 | 用另一租户的标识访问必须拒绝；为什么隐藏按钮不足以隔离数据？ |

## 3. 步骤 `08–21`：让文件成为可靠的知识

主实施章：[S6 上传解析与索引](./08-S6-上传解析与索引.md)。原理重点：上传第 `1` 节、后台摄取第 `1–4` 节、异常一致性第 `2` 节。每步沿源文件 → 文档 → 任务轮次 → 块 → 索引保存证据。

| 步骤／对应任务 | 动手与产物 | 验证和必须能解释的问题 |
| --- | --- | --- |
| `08 / S6.1` 上传契约 | 采集表单、响应和后台状态，画传输与处理两条时间线 | `HTTP` 成功但文档为 `failed` 时，页面应显示什么？ |
| `09 / S6.2` 文件与资源 | 保存原件，使用受保护读取入口，记录资源绑定 | 非法文件名、超限文件和越权下载失败；展示名为什么不能直接当路径？ |
| `10 / S6.3` 文档与去重 | 保存文档、标签、内容哈希与资源关系；注入落库失败 | 同名不同内容不会被错误去重；文件已保存而落库失败，谁清理孤立文件？ |
| `11 / S6.4` 异步受理 | 上传返回真实标识，后台执行前重新加载有效上下文 | 投递失败可见；进程内异步为什么不是持久队列？ |
| `12 / S6.5` 最小文本解析 | 输入固定文本，输出正文、元数据和来源位置 | 空正文、损坏内容不伪装成功；解析与分块的职责有什么不同？ |
| `13 / S6.5` 接解析服务 | 接 `DocReader`，比较文本型 `PDF` 的正文与页码 | 仅协议允许的不支持方法才回退；超时不能伪装成不支持；流式解析为何仍可能占内存？ |
| `14 / S6.6` 普通分块 | 固定大小、重叠和边界，保存有序块及来源 | 重跑同轮任务不重复插块；表格和长段落有没有丢失内容？ |
| `15 / S6.6` 父子分块 | 建立明确父子关系，保留审批条件及例外规则 | 能从子块找回父块；为何不能把父子块无区别重复索引？ |
| `16 / S6.7` 建索引 | 按实际配置写向量或关键词索引，携带块与文档身份 | 注入“块成功、索引失败”，重跑后可收敛；查询为何要用相同向量空间？ |
| `17 / S6.8` 图片汇合 | 用可控图片任务验证成功、最终失败、跳过后触发后处理 | 中间重试不结算；重复终态不重复扣减；图片计数与增强计数为何分开？ |
| `18 / S6.8` 增强汇合 | 先接摘要，再按配置接问题生成；记录主状态和各增强状态 | 一个增强失败仍能结束等待；取消或旧轮次结算不能推进新状态；`completed` 为何不代表每项成功？ |
| `19 / S6.10` 重新处理与删除 | 分别实现重传、队列重试、重解析、取消解析、异步删除 | 暂停旧任务、发起新轮次后放行旧任务；不能回写或复活已删资料；取消为何不等于删除？ |
| `20 / S6.9` 页面观察真实状态 | 接上传队列、列表轮询、预览；隔离租户和页面切换前的旧响应 | 传输完成仍可显示处理中；两个轮询入口各负责谁？刷新后不能继续假定持有原 `File` |
| `21 / S6.4、S6.10` 停滞与重启 | 暂停任务、终止测试进程，检查持久状态与所选模式的恢复策略 | 能区分排队慢、模型慢、合法待办与孤立任务；巡检依据是什么，人工恢复会否重复执行？ |

步骤 `17–18` 先用替身验证计数与状态，再接真实任务。图谱与 `Wiki` 的具体业务在步骤 `43–45` 完成；启用了它们的配置不能提前标记全量通过。步骤 `21` 在学习模式证明限制和可恢复记录，真实生产队列在步骤 `59` 再验。

## 4. 步骤 `22–30`：让问题找到可解释的证据

主实施章：[S7 检索与证据组织](./09-S7-检索与证据组织.md)。原理重点：用户提问与检索第 `2–3` 节、证据与流式回答第 `1` 节。此阶段先观察独立检索，不用模型的流畅回答掩盖找错资料。

| 步骤／对应任务 | 动手与产物 | 验证和必须能解释的问题 |
| --- | --- | --- |
| `22 / S7.1` 固定检索题集 | 为采购、设备、例外、无答案问题记录预期文档与片段 | 预期来源事先确定；答案恰好正确但来源不对算不算通过？ |
| `23 / S7.2` 范围授权 | 将知识库、文档、标签选择转换成可信查询范围 | 仅标签请求与空范围各自走哪条路？混入越权标识不能扩大范围 |
| `24 / S7.3` 单路召回 | 用确定性索引先查到目标块，保存候选清单 | 查不到时能分清范围错误与未建索引；此时无需调用聊天模型 |
| `25 / S7.4` 模型分组与关键词 | 按模型空间分组，增加实际已建的关键词路径 | 不同模型同维度也不能混搜；向量失败是否真的有关键词索引可回退？ |
| `26 / S7.5` 融合和重排 | 对比各路候选、融合排名与重排结果 | 不直接相加不同分数；重排异常与零候选分别验证，并记录延迟变化 |
| `27 / S7.6` 上下文补全 | 去重、回补父块或相邻块，再进行最终裁剪 | 命中审批人时仍带金额及例外；重复上下文为什么会挤占预算？ |
| `28 / S7.7` 引用与预算 | 建证据到文档、块、页码的映射，输出受控上下文结构 | 被裁掉的内容不冒充模型依据；仅存一个块标识为何不足以展示历史引用？ |
| `29 / S7.8` 来源展示 | 在原版入口接检索和来源预览，按权限隔离缓存 | 切租户、删除来源、撤销共享后不能泄露原文；命中和有权预览是两个检查点 |
| `30 / S7.9` 检索三类结局 | 分别注入真实无结果、服务失败和用户取消 | 无结果可走约定兜底，服务故障可诊断，取消不触发兜底；先定位最早偏差再调整参数 |

阶段交付是一份能从问题追到来源的检索报告，至少保留查询范围、模型配置、候选、最终证据及失败类型；不要求记录受保护全文。

## 5. 步骤 `31–40`：让一轮答案可靠结束

主实施章：[S8 会话与流式问答](./10-S8-会话与流式问答.md)。原理重点：用户提问第 `1–2` 节、证据与流式第 `1–2` 节、停止恢复第 `1–2` 节。

| 步骤／对应任务 | 动手与产物 | 验证和必须能解释的问题 |
| --- | --- | --- |
| `31 / S8.1–S8.2` 消息身份 | 创建会话、用户消息、助手占位，先加载固定历史 | 占位失败不留半轮；并发请求按服务端规则受控；会话创建为什么不等于开始生成？ |
| `32 / S8.3` 问题理解与输入 | 用“那设备呢”等多轮问题比较原问题、检索改写、最终模型输入 | 改写不覆盖用户原话；历史、证据、附件、系统要求共用预算；文档指令不扩大权限 |
| `33 / S8.4` 可控事件生产 | 假模型在首段前、片段后可暂停和报错；画生产、缓存、传输、落库边界 | 断开浏览器后观察谁继续工作；事件缓存为何不是历史数据库？ |
| `34 / S8.5` 流协议 | 保持外层 `message`、业务 `response_type`，测试拆包、合包、跨块字符和心跳 | 握手关联、引用、正文和结束能正确解析；内部事件名称能否直接当浏览器协议？ |
| `35 / S8.6` 前端归约 | 分离传输与消息更新；保存助手标识并隔离旧流代际 | 快速切会话后放行旧回调，不能串正文、引用、标题或清空新输入 |
| `36 / S8.7` 保存后完成 | 保存答案、引用、用量及状态，再对外发布完成 | 注入保存失败，保留屏幕内容并显示错误；`answer.done`、`complete`、业务成功为何不同？ |
| `37 / S8.8` 服务端停止 | 前端隔离旧事件，服务端校验目标并传递停止信号 | 分别在检索中、首段前、生成中停止；重复停止和越权停止有证据 |
| `38 / S8.9` 刷新与续流 | 先恢复历史，再按已有助手标识续接；回放不重复追加 | 不重新提交已接受的问题；缓存过期、进程重启、普通与智能体流恢复条件分别验证 |
| `39 / S8.10` 富文本与引用 | 接原版消息、代码、图表、图片及引用视图，保留安全清理 | 恶意内容不执行；长回答可操作；来源删除后提示清楚，刷新引用仍有正确身份 |
| `40 / S8.11` 真实完整闭环 | 用真实解析器和模型重复上传、检索、提问、停止/完成、刷新与引用 | 保存命中与事实约束、耗时及限制；再做一次沿标识排错，不能只凭答案好看通过 |

主链路完成后，应能不看教程解释：源文件在哪、正文在哪、索引里有什么、谁可以搜、模型实际收到什么、答案何时保存、断线后怎样找到同一轮。

## 6. 步骤 `41–58`：沿主链路理解整个产品

详细功能与失败清单见 [S9 完整功能逐项复刻](./11-S9-完整功能逐项复刻.md)，术语及原版入口见 [功能地图](./92-知识词典与原版功能地图.md)。以下是学习切片；每行仍须展开固定基线的全部功能，不以“一项练习通过”代替整组完成。

| 步骤／对应任务 | 接在主链路哪里，按什么顺序做 | 产物与理解检查 |
| --- | --- | --- |
| `41 / S9.1` 分类与批量管理 | 文档管理：标签 → 文件夹 → 移动 → 批量部分失败 | 删标签不删文档；树不能成环；能解释目录位置与检索范围的关系 |
| `42 / S9.1` 手工知识与 `FAQ` | 摄取及查询：创建问答 → 导入导出 → 专用命中及上下文 | 问题与答案正文分离；高置信策略不误用于普通文档；导入错误可定位 |
| `43 / S9.1` `Wiki` 阅读和版本 | 知识整理：目录 → 页面 → 来源 → 编辑 → 历史回滚 | 两人并发编辑不会静默覆盖；页面来源与文档不是同一个生命周期 |
| `44 / S9.1` `Wiki` 待办与收敛 | 摄取后处理：持久待办 → 批处理 → 汇合 → 来源撤回 | 重跑不重复造页；文档完成不等于知识库级整理全部结束；撤回不误删共享页 |
| `45 / S9.1` 图谱 | 摄取及检索：实体关系 → 证据关联 → 检索及展示 | 每条关系可追到有权限的证据；图谱关闭时普通文件问答仍按配置工作 |
| `46 / S9.2` 网页与数据源 | 摄取入口：抓取 → 连接测试 → 同步 → 增量、删除和取消 | 来源标识稳定；同步故障不被当成全部删除；重定向后仍校验地址 |
| `47 / S9.2` 多格式与多模态 | 解析和证据：扫描件、表格、图片、音视频逐格式接入 | 比较正文、定位、图片识别与模型选择；预览资源受保护，不能用文本测试替代全部格式 |
| `48 / S9.3` 消息关系 | 消息持久化：会话管理 → 编辑重试 → 分支 → 回退 | 生成中回退后旧流不污染新分支；历史索引、推荐等旁路失败不覆盖主答案 |
| `49 / S9.3` 附件、语音与产物 | 来源及输出：临时附件 → 转写 → 发送 → 生成文件 → 预览删除 | 会话附件不自动成为永久知识；产物按会话与用户授权，不能读取任意磁盘路径 |
| `50 / S9.4` 智能体与工具循环 | 问答编排：无工具 → 确定性只读工具 → 多步运行 → 取消 | 时间线对应真实工具调用；模型参数仍校验，循环有上限与超时 |
| `51 / S9.4` 审批、技能、记忆与协作 | 执行控制：审批与暂停恢复 → 技能 → 记忆 → 子任务 | 拒绝不执行，重复批准不重复写；恢复重新授权，父取消传到子任务，删除记忆不再注入 |
| `52 / S9.5` `MCP` 与凭据 | 工具边界：凭据 → 外部服务 → 工具目录 → 对外端点 | 说清调用外部工具和提供本系统能力的方向；掩码不覆盖密钥，撤权后调用失败 |
| `53 / S9.5` 沙箱 | 工具运行环境：创建 → 命令 → 终端/浏览器 → 文件快照 → 释放 | 真实会话可连接；过期凭据拒绝，取消后进程和资源清理，访问边界不越到宿主机 |
| `54 / S9.6` 自动化与消息渠道 | 新触发入口：手动 → 定时 → 重复触发 → 授权测试渠道回调 | 时区正确；重复回调不重复副作用；外部身份不自动拥有内部权限 |
| `55 / S9.7` 组织与共享 | 权限扩展：邀请 → 角色 → 成员移除 → 资源共享及撤回 | 撤回后列表、检索、引用、下载、运行都生效，不能仅隐藏页面入口 |
| `56 / S9.7` 系统和身份管理 | 运行治理：`API Key`、`OIDC`、初始化、设置、配额、队列与审计 | 逐角色测试管理接口；重复初始化不覆盖数据；设置作用域及生效时间清楚 |
| `57 / S9.8` 其他运行入口 | 新客户端：嵌入访客 → 宿主通信 → 桌面 → 其他基线客户端 | 各自认证、打包与真实运行证据；浏览器通过不能替代桌面验收 |
| `58 / S9.9` 跨页面体验 | 全部页面：语言 → 主题字体 → 键盘焦点 → 窄屏长内容 | 同条件截图及实际操作对照；空、加载、失败、禁用状态齐全 |

可以按现有依赖微调顺序。例如共享能力在步骤 `55` 补全，但主链路的基础授权必须在步骤 `05` 就实现；如果原版样例依赖共享，提前补相应授权切片，不允许临时绕过权限。

## 8. 用五次检查证明理解在增长

1. **步骤 `07` 后：** 从页面创建知识库追到数据库，解释认证、业务和仓储分别负责什么。
2. **步骤 `21` 后：** 不看图画出上传、解析、索引、两次汇合与删除的关系；展示一次旧轮次不能回写的证据。
3. **步骤 `30` 后：** 解释一次问题为何命中、为何排序、为何保留这些证据；换一个租户再做相同查询。
4. **步骤 `40` 后：** 对比正常完成、保存失败、停止、刷新四条时间线；用同一助手标识说明恢复不是重跑。
5. **步骤 `60` 后：** 选一种新入口或资料格式，指出可以复用哪些已有层、哪些边界必须重新验收；再从日志定位一次故障。
