## 3. 已实现能力清单

- 服务启动、`/health`、Swagger、CORS、请求 ID、统一错误处理和日志中间件。
- JWT 注册/登录/刷新/退出、当前用户、密码策略和基础角色依赖。
- 模型 CRUD、默认模型、OpenAI-compatible chat、embedding、rerank 和连通性测试。
- 知识库 CRUD、知识文件上传、解析、分块、向量化和本地存储。
- SQLite/Lite 模式下的关键词 + 向量混合检索；生产向量库仍需替换实现。
- 会话、消息历史、SSE 问答、引用持久化和基础停止流程。
- 标签、文件夹、FAQ、Wiki 页面树、版本和图谱接口。
- Agent CRUD、ReAct 引擎、内置检索工具和 `agent-chat` SSE。
- MCP Endpoint/Service 管理、工具目录、连接测试、凭证和工具审批。

每项能力必须以对应阶段报告和 `tests/e2e/` 测试为证据；只有源码文件存在时，状态仍应记为“部分完成”。

## 4. 未实现或未达切流标准的能力

以下内容在当前 `route_matrix.md` 中仍显示为 Python 未实现，按优先级处理：

### 第一优先级：前端已调用

- 认证补全：自动初始化、OIDC、邀请注册、用户偏好、浏览器登录态和 API Key 管理。
- Agent 补全：Agent 分享、嵌入频道、IM 频道、建议问题、提示词、工具审批和 OAuth resolution。
- 会话补全：附件、临时文档、fork、rewind、steer、停止、后台工作、语音转写和浏览器连接。
- 资源补全：文件预览/下载、artifact、受保护图片和引用资源。
- 组织与租户：成员、邀请、角色变更、共享资源、租户切换后的缓存失效。
- 系统管理：用户、系统设置、运行队列、审计日志、部署能力和限流配置。

### 第二优先级：后端已存在但证据不足

- 所有接口的 Go/Python 响应字段、状态码、错误结构和分页语义逐项对照。
- PostgreSQL 真实数据库上的并发迁移、事务回滚和旧版本数据兼容。
- Redis/ARQ 的重试、幂等、取消、死信、任务进度和重启恢复。
- 生产对象存储、真实向量库、重排服务、多厂商模型超时和密钥轮换。
- SSE 全事件协议、断线恢复、请求代际、防止旧流覆盖新流。

### 第三优先级：暂缓项目

桌面 `Wails`、BrowserSkill、Cube/E2B 沙箱、多向量库全覆盖、全部 IM 渠道和低频旧兼容路径暂不纳入当前切流批次。

## 5. 进度更新规则

每完成一个接口域，按以下顺序更新：

1. 在 `app/api/v1/routes`、schema、service、repository 中实现。
2. 增加或更新 `tests/e2e/test_<domain>_api.py`。
3. 运行 `scripts/generate_route_matrix.py`，更新 `route_matrix.md`。
4. 运行对应阶段测试，创建 `stage_report_phaseX.md`。
5. 只有“测试通过 + 前端实际调用通过 + 数据库落盘核验通过”才把状态改为 `已验收`。
6. 更新本文件的阶段表、已实现清单、未实现清单和下一步。
