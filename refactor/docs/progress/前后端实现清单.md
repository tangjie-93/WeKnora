# WeKnora 前后端实现清单

本文记录当前源码中已经存在的前端和 Python 后端能力，并用 Go 后端作为兼容基线。状态含义：

- `已实现`：源码、接口或页面存在，并有对应测试/阶段报告。
- `部分实现`：主流程存在，但缺少异常、权限、生产依赖或完整契约。
- `未实现`：当前 Python 后端或前端没有可用实现。

## 5. 当前迁移优先级

1. 先补“前端已经存在且用户主流程会调用”的 Python 接口：认证补全、附件/文件预览、组织成员、嵌入聊天。
2. 再补生产依赖：Redis/ARQ 任务、对象存储、真实向量库、SSE 完整事件协议。
3. 最后迁移低频管理、桌面端、BrowserSkill、沙箱和全部 IM 渠道。

每次更新后运行：`py -3.13 scripts/generate_route_matrix.py` 和 `py -3.13 scripts/update_refactor_progress.py`，并同步修改本清单中的联通状态。
